# scripts — 仓库维护脚本目录

## 目录职责

- 存放安装、打包、检查、离线处理等仓库级脚本
- 支撑开发环境准备与日常维护任务

## 当前内容

- `install.sh`：安装脚本
- `check_dependency_config.py`：依赖配置检查
- `offline_bundle.py`：离线资源处理
- 其他 shell 辅助脚本

## 修改约束

- Python 脚本继续遵守仓库约束：不要引入 `argparse`
- 脚本优先可重复执行，副作用要明确
- 涉及路径、权限、删除动作时先写清楚假设
- 与训练/推理强耦合的逻辑应留在对应目录，不要全部堆进 `scripts/`

## 验证建议

- 改动 shell 脚本后至少检查关键路径与错误分支
- 改动 Python 脚本后补最小可运行说明
