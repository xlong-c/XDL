XDL Dataset 模块结构说明

本文说明 xdl/dataset 的通用数据集结构, 包括 注册入口, record/manifest 模板, folder/sidecar 组织, classification/regression/segmentation/detection/image-text/text/pair/triplet/image-edit 任务文件, transform 和 collate 组件. 本文刻意排除 hair 系列特殊数据集, 因为它们属于项目私有数据形态.

推荐新增数据集时 先复用现有模板. 所有数据集统一使用 Record* / ImageEdit* 名称.

一. 模块分层

注册入口

文件: __init__.py

集中导入并注册 DATASET, TRANSFORM, COLLATE. YAML 的 registry:Name 最终都从这里进入.

公共 helper

文件: utils.py

负责读取 manifest, 解析相对路径, 构造 sample_id, 扫描图片目录, 生成 basename sidecar 配对和 tensor 转换.

任务 Dataset

文件: classification.py, segmentation.py, detection.py 等

按任务语义拆分 dataset, 包括分类, 回归, 分割, 检测, 图文, 文本, pair, triplet 和通用 record.

Transform

文件: transforms.py

覆盖 image-mask, image-boxes 和多图编辑样本这类需要同步几何变换的场景.

Image edit 模板

文件: image_edit.py

覆盖 source/target/reference/mask/prompt 多图编辑样本, 并提供专用 collate.

Collate

文件: collate.py

提供 padding, dict batch, detection 和 image edit 的 batch 拼接逻辑.

二. 数据流

通用数据链路可以看成五步. Dataset 只关心单样本, DataLoader 和 collate 才负责 batch.

通用 record .jsonl / .json / .csv manifest, 每条为任意字段 dict RecordDataset dict (原始 manifest 行, 可经 transform 处理)

五. 数据集拆分工具

模块提供两个轻量拆分函数, 封装 torch 的 random_split 并内置 seed 确定性:

函数 用途
split_dataset(dataset, lengths, *, seed=42) 按 lengths 将数据集确定性随机拆分为多个 Subset, 返回 list[Subset]
train_val_split(dataset, val_ratio=0.1, *, seed=42) 按比例拆分为训练集和验证集, 返回 tuple[Subset, Subset]; val_ratio 为 0 时 val 为空, 为 1 时 train 为空

六. 新增数据集时怎么最小化代码

优先判断问题属于哪一层. 不要为了一个字段名不同就新增完整 dataset 类.

  • 字段能用 JSONL/JSON/CSV 表达时, 优先使用 manifest 模板.
  • 只是 manifest 字段名不同, 通过 image_key, label_key, text_keys 等参数映射.
  • 只是同名文件对齐, 优先复用 BasenameAlignedDataset 或现有 sidecar 模板.
  • 只是 batch 方式不同, 新增 collate, 不要改 dataset.
  • 只是增强不同, 新增 transform, 不要新增 dataset.
  • 确实是新语义形态时, 继承 RecordDatasetBase 写薄 adapter, 再在 __init__.py 注册.
class MyRecordDataset(RecordDatasetBase):
    def __getitem__(self, index: int) -> dict[str, Any]:
        base_index, record = self._record_at(index)
        image_path = self._resolve_record_path(record, "image")
        return {
            "image_path": str(image_path),
            "sample_id": self._sample_id_from_path(record, image_path, base_index),
        }
