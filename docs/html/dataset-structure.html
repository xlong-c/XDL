XDL Dataset 模块结构说明

本文说明 xdl/dataset 的通用数据集结构, 包括注册入口, record/manifest 模板, sidecar 模板, dense prediction 模板, image edit 模板和 collate 组件. 本文刻意排除 hair 系列特殊数据集, 因为它们属于项目私有数据形态.

推荐新增数据集时先复用现有模板. 新代码优先使用 Record* / ImageEdit* 名称, 历史 Manifest* 名称继续兼容.

一. 模块分层

注册入口

文件: __init__.py

集中导入并注册 DATASET, TRANSFORM, COLLATE. YAML 的 registry:Name 最终都从这里进入.

公共 helper

文件: _records.py, _paths.py

负责读取 manifest, 解析相对路径, 构造 sample_id, 扫描图片目录, 生成 basename sidecar 配对.

通用模板

文件: templates.py

覆盖 image folder, classification, regression, multilabel, image-text, text, pair, triplet 和 raw record.

Dense 模板

文件: dense.py

覆盖 image-mask, image-boxes, segmentation, detection 和对应同步 transform / detection collate.

Image edit 模板

文件: image_edit.py

覆盖 source/target/reference/mask/prompt 多图编辑样本, 并提供专用 collate.

Collate

文件: collate.py

提供 padding 和 dict batch 拼接逻辑. 检测和 image edit 的专用 collate 放在对应任务模块里.

二. 数据流

通用数据链路可以看成五步. Dataset 只关心单样本, DataLoader 和 collate 才负责 batch.

三. 文件职责

文件 核心对象 职责
_records.py load_manifest_records, resolve_record_path, build_sample_id 统一 JSONL/JSON/CSV 读取, 相对路径基于 manifest 目录解析, sample_id 从显式字段或 fallback 构造.
_paths.py collect_image_paths, collect_sidecar_samples 统一图片扩展名过滤, 递归扫描, basename sidecar 配对, 缺失 sidecar 的 error/skip 策略.
templates.py RecordDatasetBase, ImageFolderDataset, RecordTextDataset 等 承载大多数非 dense 通用样本语义, 是新增 manifest 数据集的首选参考文件.
dense.py ImageMaskTransform, ImageBoxesTransform, RecordSegmentationDataset, RecordDetectionDataset 处理 image-mask 和 image-boxes 这类需要同步几何变换的样本.
image_edit.py ImageEditDataset, PairedImageTransform 处理 source/target/reference/mask/prompt 多图编辑训练样本.
collate.py PadCollate, DictCollate 提供基础 batch 拼接能力, 适合变长序列和通用 dict 样本.
basic.py, vision_datasets.py SyntheticClassificationDataset, MNISTDataset, CIFAR10Dataset 提供 smoke test 数据集和 torchvision 常见数据集封装.

四. 模板选择表

数据形态 磁盘结构 推荐模板 返回结构
纯图片 images/000.png ImageFolderDataset {"image", "sample_id", "image_path?"}
目录分类 root/class_name/image ImageFolderClassificationDataset (image, target)
manifest 分类 {"image": "...", "label": "cat"} RecordClassificationDataset (image, target)
回归 {"image": "...", "target": 0.7} RecordRegressionDataset (image, target)
多标签 {"image": "...", "labels": ["a", "b"]} RecordMultiLabelClassificationDataset (image, multi_hot_tensor)
图文配对 manifest 或 000.png + 000.txt RecordImageTextDataset, ImageTextSidecarDataset {"image", "text", "sample_id"}
分割 manifest 或 images/000.png + masks/000.png RecordSegmentationDataset, ImageMaskSidecarDataset {"image", "mask", "sample_id"}
检测 {"image": "...", "boxes": [[...]], "labels": [...]} RecordDetectionDataset + DetectionCollate {"image", "boxes", "labels", "sample_id"}
文本或指令 {"prompt": "...", "response": "..."} RecordTextDataset {"text", "target_text?", "sample_id"}
pair/triplet manifest 明确字段 RecordPairDataset, RecordTripletDataset {"image_a", "image_b"} 或 {"anchor_image", "positive_image", "negative_image"}
图像编辑 source_image + target_image + reference_image? + edit_mask? ImageEditDataset + ImageEditCollate {"source_image", "target_image", "reference_image", "edit_mask", "prompt"}

五. 新增数据集时怎么最小化代码

优先判断问题属于哪一层. 不要为了一个字段名不同就新增完整 dataset 类.

  • 字段能用 JSONL/JSON/CSV 表达时, 优先使用 manifest 模板.
  • 只是 manifest 字段名不同, 通过 image_key, label_key, text_keys 等参数映射.
  • 只是同名文件对齐, 优先复用 sidecar helper 或现有 sidecar 模板.
  • 只是 batch 方式不同, 新增 collate, 不要改 dataset.
  • 只是增强不同, 新增 transform, 不要新增 dataset.
  • 确实是新语义形态时, 继承 RecordDatasetBase 写薄 adapter, 再在 __init__.py 注册.
class MyRecordDataset(RecordDatasetBase):
    def __getitem__(self, index: int) -> dict[str, Any]:
        base_index, record = self._record_at(index)
        image_path = self._resolve_record_path(record, "image")
        return {
            "image_path": str(image_path),
            "sample_id": self._sample_id_from_path(record, image_path, base_index),
        }
