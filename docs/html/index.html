推荐阅读路线

第一次看 XDL / XQT 时,按这条路走. 每一步都可以直接跳到对应层级的 Markdown 正文.

1
安装和验证 确认环境,依赖,可运行入口和基础测试命令.
使用#安装
2
框架是什么 理解 XDL 的定位,核心分层,训练入口和生命周期.
架构#XDL
3
怎样写 YAML 理解 setup_from_yaml(),schema v1 和 target + params 组织方式.
使用#配置
4
怎样接数据集 先看模板选择,再看通用 dataset 模块结构图.
阅读#Dataset
5
哪些 API 稳定 区分 Stable, Provisional 和 Internal,避免依赖内部实现.
架构#API
6
模块边界和后续方向 查子模块职责,再看当前仍有效的优化计划.
使用#工作流
7
XQT 压缩与部署 查看量化,剪枝,算子优化,导出和分析的长期工作文档.
架构#XQT

写代码前看什么

改动不同区域时,优先回到对应层级的 MD. 这也是 Codex 修改代码前应使用的路线.

改动范围 先读 目的
训练生命周期,Trainer,CoreModel,Callback 架构#XDL 确认手动优化,batch 迁移,日志和回调顺序.
YAML 配置,schema,target + params 使用#配置 确认配置主链路和 OmegaConf 约束.
数据集模板,collate,manifest 阅读#Dataset 确认应该复用模板,新增 thin adapter,还是只新增 transform/collate.
公开入口,导出符号,兼容策略 架构#API 确认 Stable / Provisional / Internal API 边界.
目录职责或模块迁移 架构#XDL 确认逻辑应该放在哪个子模块.
xqt/ 模型压缩,图变换,导出适配和 benchmark 架构#XQT 确认工具链边界,配置方式,现有能力和现状约束.
