推荐阅读路线

第一次看 XDL 时,按这条路走. 每一步都可以直接跳到高密度 MD.

1
安装和验证 确认环境,依赖,可运行入口和基础测试命令.
INSTALL.md
2
框架是什么 理解 XDL 的定位,核心分层,训练入口和生命周期.
XDL.md
3
怎样写 YAML 理解 setup_from_yaml(),schema v1 和 target + params 组织方式.
CONFIG.md
4
怎样接数据集 先看模板选择,再看通用 dataset 模块结构图.
DATASET.md
5
哪些 API 稳定 区分 Stable, Provisional 和 Internal,避免依赖内部实现.
API.md
6
模块边界和后续方向 查子模块职责,再看当前仍有效的优化计划.
边界速查

写代码前看什么

改动不同区域时,优先回到对应 MD. 这也是 Codex 修改代码前应使用的路线.

改动范围 先读 目的
训练生命周期,Trainer,CoreModel,Callback XDL.md 确认手动优化,batch 迁移,日志和回调顺序.
YAML 配置,schema,target + params CONFIG.md 确认配置主链路和 OmegaConf 约束.
数据集模板,collate,manifest DATASET.md 确认应该复用模板,新增 thin adapter,还是只新增 transform/collate.
公开入口,导出符号,兼容策略 API.md 确认 Stable / Provisional / Internal API 边界.
目录职责或模块迁移 xdl-functional-boundary.md 确认逻辑应该放在哪个子模块.

维护规则

当框架行为,配置字段,注册名称或 API 边界变化时,先更新对应 MD 和测试. 如果 HTML 页面覆盖了同一主题,再同步更新 HTML,确保好读版不漂离真实实现.
