XQT 压缩与部署阅读页

XQT 是 xqt/ 下的实验性模型压缩与部署工具链,覆盖量化,蒸馏,剪枝,扩散少步蒸馏和部署格式导出. 事实源仍是 docs/md/XQT.md 和源码,本文只做阅读版地图.

当前能力已覆盖 CPU smoke,本地 CIFAR-100 ONNX Runtime QDQ 和可选后端 adapter. CUDA FP8 和 TensorRT engine 生成仍需目标硬件单独验证.

二. 当前模块

core / pipeline

负责 structured config, manifest, registry, pass manager, preflight 和 YAML runner. 顶层 xqt.load_xqt_config, xqt.run_xqt_recipe 和 xqt.preflight_xqt_config 已列为 Provisional.

quant

包含 torchao adapter, ONNX Runtime static QDQ INT8 adapter, calibration statistics, layer sensitivity 和 policy helper.

distill / prune

包含 logit KD, feature/relation loss, teacher cache, HF text bundle, global L1 pruning, structured rewrite 和 prune + KD schedule.

diffusion_distill

包含 timestep schedule, prompt/latent/trajectory cache, consistency/LCM style loss 和 sampling report metadata.

export

包含 torch.export, TorchScript fallback, ONNX export/checker/runtime diff, TensorRT trtexec 命令和性能阈值报告, OpenVINO optional adapter, ExecuTorch, pnnx/ncnn 和 MNNConvert adapter.

xdl_adapter

从 XDL TrainSetup-like 对象或 PyTorch/XDL-style checkpoint 创建 XQT context,用于把训练产物接入压缩 pipeline.

四. 后端边界

可选依赖不进入基础承诺. TensorRT, OpenVINO, ExecuTorch, ncnn, MNN 和 diffusers pipeline 都通过 adapter 隔离. 缺少二进制或 Python 包时,测试优先覆盖命令构造和 dry-run,真实产物需要在目标机器单独验收.
后端 当前接入方式 验证重点
ONNX Runtime ONNX diff + static QDQ quantization checker 通过,输出 diff,校准样本数和 QDQ 图产物.
TensorRT trtexec command adapter + performance parser precision flag,dynamic shape profile,engine checksum,性能摘要和阈值报告. 当前环境缺 trtexec,只能验证 dry-run 和解析逻辑.
OpenVINO optional Python adapter IR export,runtime diff,缺依赖时错误清楚.
Mobile ExecuTorch .pte, pnnx, onnx2ncnn, MNNConvert 命令参数,输出路径,dry-run 和真实二进制可用性.

五. 验证命令

当前建议先跑本地 smoke 和静态检查. 全仓测试已覆盖 XQT 相关路径和 XDL manifest 兼容别名.

Python 侧可选依赖可以按需安装: pip install -e ".[xqt]", pip install -e ".[xqt-hf]", pip install -e ".[xqt-diffusion]" 或 pip install -e ".[xqt-all]".

python -m pytest tests/xqt tests/config/test_structured.py tests/utils/test_registry.py -q
python -m ruff check xqt tests/xqt
python -m compileall -q xqt tests/xqt
python -m pytest tests -q
XQT_CONFIG=xqt/recipes/image_vit_torchao_fp8.yaml xqt-preflight
XQT_CONFIG=xqt/recipes/smoke_cpu.yaml xqt-run-recipe
