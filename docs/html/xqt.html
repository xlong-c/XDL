XQT 模型优化阅读页

XQT 只关注模型本身. 它接收 PyTorch 模型, checkpoint 或导出产物, 执行量化, 剪枝, 算子优化, 导出, 误差分析和 benchmark. 训练,QAT,finetune,distillation,recovery,dataset / dataloader 和 task-level validation 不属于 XQT.

二. 当前模块

保留的都是模型侧能力.

quant

PTQ, QDQ, torchao, calibration, layer sensitivity.

prune

Unstructured, structured, N:M, block sparse, mask/rewrite.

export

ONNX, TensorRT, OpenVINO, torch.export, TorchScript, mobile adapters.

operator_opt

torch.compile-first operator optimization and backend capability reporting.

eval / benchmark

Tensor diff, layer analysis, latency, memory.

model

Smoke model helpers and forward hook output capture for analysis.

三. 明确不包含

XQT 不再承载训练相关职责.

  • training provider / evaluation provider.
  • dataset / dataloader 构建和 task-level validation.
  • finetune / distill / QAT training / recovery training.
  • teacher-student recipe, KD cache, diffusion distillation.

四. 性能分析工具

Benchmark 给基线, profiler 给瓶颈归因.

NVIDIA

nsys 看系统级 timeline,ncu 看 kernel 级 counters 和瓶颈.

ROCm / oneAPI

AMD 用 rocprof-sys / rocprof,Intel 用 VTune GPU Hotspots / Offload.

NPU / 移动端

Ascend 用 msprof,TPU 用 XProf,Arm / Qualcomm / Apple 使用各自官方 profiler.

XQT 只记录 profiler 上下文和产物到 manifest,例如 .ncu-rep,.nsys-rep,ROCm trace,VTune result 或 msprof 目录;不接管工具安装,权限,驱动版本或 GUI 工作流.
