HTML Style Templates

XDL HTML 只保留两种样式模板

本页展示仓库自有 HTML 阅读页允许使用的两种 body 模板: xdl-style-atlas 和 xdl-style-ledger. 目录专属 class 只能叠加语义和局部组件,不能另起视觉系统.

Template 01

Atlas: 入口页,导航页,速查页和交互实验页

Atlas 强调模块边界和快速跳转,适合总入口,状态面板,路线图,训练链路说明和交互式学习页面.

body xdl-style-atlas

页面通常使用 `.topbar`,`.hero`,`.section`,`.card`,`.route`,`.stat-card` 和 `.button`. 如果是交互实验页,可以叠加 `flash-attention-page` 这类语义 class 来补充局部组件.

推荐使用场景

  • 文档入口和阅读路线,例如 `docs/html/index.html`.
  • 实验性教程或可视化工具,例如 Flash Attention 交互页.
  • 需要并列展示多个模块,状态,路径或检查项的页面.

Template 02

Ledger: 长文,教程,调研报告和结构说明页

Ledger 强调正文阅读节奏和纸面感,适合概念解释,研究报告,数学教程,表格,公式和长段落.

body xdl-style-ledger

长文页面通常叠加 `math-doc-page` 或 `research-page` 这类语义 class. 语义 class 只能扩展课程图示,研究页特殊图表或少量页面专属组件.

推荐使用场景

  • 结构说明页,例如 `docs/html/dataset-structure.html`.
  • 数学教程和课程章节,例如 `learn/math/**/*.html`.
  • 研究报告和方案讨论,例如 `research/**/*.html`.

Checklist

新增或修正 HTML 的最低检查项

下面的检查项用于防止仓库再次出现第三套页面样式.

模板

每个长期 HTML 的 body class 必须包含 `xdl-style-atlas` 或 `xdl-style-ledger` 之一.

样式入口

页面必须直接引用 `xdl-doc.css`,或引用第一行 `@import` 它的目录专属 CSS.

局部扩展

目录 CSS 只能写命名空间明确的局部组件,不得复制公共版式,主题变量和通用阅读组件.

验证建议 使用搜索命令检查页面模板,内联样式属性和 CSS 入口,避免第三套视觉系统重新出现.
