# XDL Dashboard 三个设计方向对比

## 预览入口

打开 [concepts.html](../../dashboard/design/concepts.html) 查看交互设计稿. 顶部可以切换 01, 02, 03 三个方向, URL 也支持 `#a`, `#b`, `#c` 直达.

- 01 专注训练: 当前训练过程优先.
- 02 实验研究台: 多实验筛选和指标比较优先.
- 03 流程工作室: 配置, 数据流和启动前校验优先.

页面里的数据和操作都是模拟的, 不会启动或修改真实训练任务.

## 方向 01: 专注训练

### 核心定位

把一个正在运行的实验当成主工作面. 用户进入页面后先看到当前实验名称, 状态, 曲线和控制按钮, 再按需查看日志和配置.

### 主要区域

- 左侧运行队列: 训练中, 排队中, 已暂停, 已完成和失败实验.
- 主曲线: Loss / Accuracy 切换, 当前 step 和模拟 tooltip.
- 就近控制: 暂停, 保存检查点, 停止, 从检查点派生.
- 下方信息: 运行日志和实验记录.

### 适合场景

日常盯训练, 单次实验排错, 远程 SSH 场景下快速确认状态.

### 优点

- 主任务明确, 认知负担低.
- 与现有 `/api/runs/:id`, metrics, events 和 actions 接口贴合.
- 状态控制离曲线近, 暂停和检查点操作容易发现.

### 代价

- 多个实验之间的比较需要切换.
- 需要依赖选中的 run, 不适合作为大量超参实验的主界面.

## 方向 02: 实验研究台

### 核心定位

把 Dashboard 从监控单个训练, 改成用于实验筛选和结果比较的研究桌面. 用户通过状态, 设备和搜索快速缩小范围, 勾选实验叠加曲线, 再通过表格进入详情.

### 主要区域

- 左侧筛选: 状态, 设备和搜索.
- KPI 条: 进行中, 排队, 对比中和最佳验证损失.
- 对比图: 最多同时显示 4 个实验.
- 实验表: step, 进度, 验证损失, 准确率和设备.

### 适合场景

学习率扫描, 模型基线比较, 实验复盘, 同一工作空间中同时维护多个训练任务.

### 优点

- 信息密度高, 结果比较效率最高.
- 实验排序和状态筛选很直观.
- 适合后续增加标签, 负责人, 数据集和实验分组.

### 代价

- 需要批量查询或聚合多个 run 的 metrics.
- 单实验控制动作被放到详情页, 现场控制的即时性弱于方向 01.
- 桌面宽度要求更高, 移动端主要适合查看而不是比较.

## 方向 03: 流程工作室

### 核心定位

把训练配置做成节点编辑器. 新建工作流从一张空白画布开始, 用户从节点库逐步添加数据集, 预处理, 批次加载, 模型, 损失函数, 优化器, 训练循环和检查点, 再自由拖动节点排布并在检查器中声明上游输入.

### 主要区域

- 左侧节点库: 按数据, 训练和运行分组, 点击即可添加节点.
- 中部空白画布: 节点自由拖动, 网格背景保持空间感, 连线显示输入方向.
- 右侧检查器: 编辑节点名称和 target, 勾选上游节点, 查看输出形状.
- 顶部状态: 草稿, 已排队, 运行中和上次失败, 用于检查不同运行阶段.
- preflight: 区分阻断错误和可确认警告, 画布为空或缺少必需节点时禁止排队.

### 适合场景

复杂训练配置, 新用户理解训练链路, 自定义数据流, 多卡和 AMP 参数确认, 以及后续接入用户创建 workflow.

### 优点

- 用户可以从最小节点开始, 逐步搭建完整训练流水线.
- 节点位置和连线关系表达真实的配置结构, 不被固定的左到右模板限制.
- 检查器把节点参数和上游输入放在同一上下文, 修改后立即反映到 preflight.
- 后续可以自然扩展多输入节点, 分支, 合并和自定义节点.

### 代价

- 需要保存节点位置和连接关系, 不能只存一组扁平参数.
- 需要完善 cycle detection, 类型检查, 端口类型和拖拽连线交互.
- 移动端更适合查看和编辑检查器, 复杂画布仍推荐桌面端.

## 推荐顺序

既然目标是节点类型的训练搭建, 建议以 **方向 03 的空白节点画布** 作为主设计基线, 再把方向 01 和方向 02 作为画布完成后的运行监控与实验复盘页面.

推荐的页面关系是: `工作流编辑器` 负责从空白画布搭建和校验, `训练监控` 负责观察单个 run, `全部实验` 负责多 run 比较. 这样创建配置和观察结果各自有清晰的工作面, 但仍然通过 workflow snapshot, run 和 checkpoint 关联起来.

## 交互验收点

- 顶部三个方向可以切换, `#a`, `#b`, `#c` 可以直达.
- 方向 01 可以切换 run, 切换 Loss / Accuracy, 查看配置, 暂停/继续/保存检查点/停止, 过滤日志和打开新建实验对话框.
- 方向 02 可以搜索, 按状态和设备筛选, 勾选最多 4 个实验, 移除对比曲线, 排序和查看实验详情.
- 方向 03 可以从空白画布点击添加节点, 拖动节点自由排布, 在检查器中编辑 target 和上游输入, 查看动态连线, 切换草稿/排队/运行/失败状态, 看到分级 preflight 提醒, 自动排布或清空画布.
- 对话框支持关闭按钮和 Escape. 设计稿中的操作只更新页面模拟状态.
- 页面使用响应式布局, 在窄屏下侧栏折叠或堆叠, 不依赖外部网络资源.
