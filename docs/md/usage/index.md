# 使用文档入口

本文汇总 `XDL` 的使用文档. 使用层负责可执行 workflow, 安装, 验证, 输入输出和 handoff.

## 负责什么

- 提供最短上手路径.
- 提供常见工作流和验证方式.
- 说明产物, 交付和接手约定.

## 不负责什么

- 不重新定义系统边界.
- 不长篇解释架构设计.
- 不单独给出 API 兼容承诺.
