Chapters

全部章节

每章都按 "问题 -> 直觉 -> 定义 -> 计算 -> 物理例子 -> 清单" 组织.

Session 1: 第一章: 线性方程组与消元法约束与求解. 从多个线性约束能否同时满足开始, 学会用增广矩阵和初等行变换把问题化成容易读解的标准形.Session 2: 第二章: 矩阵运算与逆矩阵矩阵作为变换. 把矩阵从数字表升级为线性规则, 理解矩阵乘法是变换复合, 逆矩阵是把变换倒回去.Session 3: 第三章: 行列式面积体积缩放. 把行列式理解为有向面积或体积的缩放因子, 用它判断线性变换是否把空间压扁.Session 4: 第四章: 向量与向量空间空间与维数. 从具体箭头走向抽象空间, 理解线性组合, 张成, 线性无关, 基, 维数和四个基本子空间.Session 5: 第五章: 线性变换与坐标变换变换与坐标. 把矩阵看成线性变换在某组基下的表示, 分清对象本身和坐标数字, 理解核, 像和相似.Session 6: 第六章: 特征值, 特征向量与对角化不变方向. 寻找变换中方向不变的特殊向量, 用合适的基把复杂耦合变成按方向独立缩放.Session 7: 第七章: 内积, 正交与最小二乘距离与投影. 给向量空间加入长度, 角度和距离, 用投影解释最小二乘和工程数据拟合.Session 8: 第八章: 二次型与实对称矩阵能量与曲率. 用矩阵表达二次能量, 曲率和稳定性, 理解正定, 不定, 谱定理和 Hessian 的关系.Session 9: 第九章: 矩阵分解与数值视角稳定计算. 把矩阵拆成更稳定, 更可解释, 更易计算的部分, 理解 LU, QR, Cholesky, SVD, 伪逆和条件数.Session 10: 第十章: 工程与机器学习应用应用整合. 把前九章工具汇总到真实问题: 回归, PCA, 图像压缩, 神经网络线性层, 图算法和物理系统仿真.

Physics Thread

贯穿全课的物理问题线索

每章都把数学概念放回一个真实可解释的物理或工程场景.

静力平衡第一章把结点受力写成线性方程组, 解释消元为什么是处理约束.
电路与网络第二章用 KCL/KVL 说明矩阵和逆矩阵如何把输入电压映射成电流.
坐标系和传感器第四, 五章解释分量, 基变换, 机器人坐标和相机位姿.
振动, 能量, 稳定性第六, 八, 九章把特征值, 二次型和分解连接到弹簧系统, 模态和数值求解.

Usage

建议阅读方式

先完整读一遍主线, 再回到公式和例题处做手算.

  1. 先读每章的 "全章主线", 知道本章解决什么问题.
  2. 遇到公式先看它的对象和维度, 不要马上代数展开.
  3. 看完物理例子后, 尝试把同类问题写成矩阵形式.
  4. 最后用实战清单检查: 条件是否满足, 量纲是否一致, 结论是否能解释原问题.
