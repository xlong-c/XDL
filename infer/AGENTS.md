# infer — 推理脚本目录

## 目录职责

- 存放各类模型的推理入口
- 存放推理样例输入与输出图像

## 当前内容

- `*_infer.py`：不同模型的推理脚本
- `batch_compare.py`：批量对比脚本
- `images/`：输入样例与输出结果

## 修改约束

- 推理脚本优先保持单用途、可直接运行
- 模型权重依赖要写明来自 `others/`、`downloads/` 还是外部路径
- 复杂共用逻辑应抽到 `xdl/` 或 `tools/`，避免脚本间复制
- 图像输出尽量放在 `images/` 或明确的结果目录，避免污染源码树

## 注意事项

- 推理脚本常依赖本地权重与 GPU 环境，缺文件或显存不足先当环境问题排查
