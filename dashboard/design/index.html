最近动态

检查点

这是单个 batch 的训练路径. 点击节点可检查张量形状,配置与耗时; 连线显示数据方向.

一批数据如何完成训练?

CPU 生成样本并执行预处理, DataLoader 将 64 张图像组成 batch. 图像和标签迁移到 GPU 后, VGG 输出 10 类 logits, CrossEntropy 计算损失.

随后执行 zero_grad → backward → step. 梯度用于更新模型参数, 下一批数据使用更新后的权重.

检查点保存在哪里?

检查点由 Callback 在训练边界保存. 它是模型与优化器状态的快照, 与每批数据的流动分开显示.

  • 保存内容: model + optimizer + epoch + global step
  • 策略: 每个 epoch 保存, 也可手动触发
  • 从检查点恢复会创建关联的新实验

体验这个训练工作台

HTML 交互设计稿 / V02

  • 选择实验: 顶部卡片或全部实验列表可切换运行记录.
  • 查看指标: 在 Loss / Accuracy 之间切换, 移入曲线查看 step 数值.
  • 追踪数据: 点击数据流节点检查输入,输出和配置.
  • 操作训练: 暂停,继续,保存检查点和停止会更新模拟状态.
  • 创建实验: 填写参数后进入模拟队列; 不会启动训练.
  • 键盘: Tab 聚焦控件, 方向键切换详情标签, Esc 关闭弹窗.
