# tools — 数据与工程工具目录

## 目录职责

- 存放数据处理、图像处理、环境检查、模型辅助脚本等工具
- 为训练、推理、数据集准备和工程维护提供外围能力

## 子目录

- `agent/`：Codex/OpenCode/Claude 等 Agent 辅助工具与说明
- `data_processing/`：通用数据处理
- `dataset/`：数据集整理、复制、重命名、清洗、下载
- `experiments/`：一次性或研究期工具，保留需写清上下文
- `image/`：图像处理与检测
- `ml/`：模型侧辅助脚本
- `setup/`：环境准备与依赖检查
- `system/`：系统级操作脚本，例如启动盘制作
- `test/`：硬件或设备测试
- `video/`：视频处理

## 修改约束

- 工具脚本优先单职责、可复用、可直接运行
- Python 脚本继续遵守仓库约束：不用 `argparse`
- 破坏性操作要显式，特别是删除、覆盖、批量重命名
- 与框架主逻辑强相关的抽象应下沉到 `xdl/`，不要把 `tools/` 做成杂项核心层
- 不提交明文 token、个人绝对路径产物、运行缓存或 notebook 输出

## 开发建议

- 写清楚输入目录、输出目录和副作用
- 图像/数据类工具尽量保留 dry-run 或最小验证路径
- 新增工具优先放进已有分类；确实是临时实验才放 `experiments/`
